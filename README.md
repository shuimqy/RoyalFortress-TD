# RoyalFortress TD · 王国边境塔防

一款使用 Unity 制作的 2D 奇幻塔防游戏。守住通往王宫的道路，用有限的金币部署防御塔，抵御骷髅军团、重甲兽人与操纵天气的灾厄巫师。

![王国边境塔防](Assets/Art/Menu/royal-fortress-title-v1.png)

## 守住防线

从底部卡栏拖出防御塔，放到道路旁的空石台上购买建造。每张地图提供固定的启动资金，击败敌人可获得更多金币，用来补强防线。

准备好后手动开启下一波。战斗中也能继续部署，让火力覆盖道路的转弯与交汇处。消灭全部波次即可获胜；敌人抵达终点会扣除基地生命，生命耗尽则防守失败。

## 战役入口

| 地图 | 战场特点 | 建塔位 | 波次 | 启动资金 |
| --- | --- | ---: | ---: | ---: |
| 边境要塞 | 多路来袭，第三波开放墓穴支路 | 7 | 3 | 300 金币 |
| 圣林加护 | 三路守护古树圣坛，守住两波积蓄净化脉冲 | 8 | 8 | 300 金币 |
| 亡者之门 | 枯骨墓域防守，守住最后一波后封印传送门 | 10 | 7 | 300 金币 |

主菜单按以上顺序进入关卡，沿用金币、拖卡建塔、天气与暂停系统。原有 `RoyalFortressGameplay` 和 `EmeraldSwitchback` 场景均保留；翡翠回廊仍可在编辑器直接打开，12 个塔位、5 波、380 初始金币不变。

地图支持缩放与平移。沿着蜿蜒道路布置交叉火力，让同一座塔在敌人折返时获得多次攻击机会。

## 四种防御塔

| 防御塔 | 价格 | 作战特点 |
| --- | ---: | --- |
| 箭塔 | 90 金币 | 快速单体射击，适合补充持续火力 |
| 冰霜塔 | 110 金币 | 持续光环使范围内敌人减速 45%，为攻击塔争取时间 |
| 法师塔 | 140 金币 | 发射穿甲追踪飞弹，对付重甲敌人 |
| 投石塔 | 160 金币 | 范围溅射攻击，打击聚集的敌群 |

拖动塔卡时可以预览塔体与射程，空石台会高亮。只有成功建造才会扣除金币；金币不足时，卡片会变暗。

## 敌人与天气 Boss

骷髅兵行动较快，击败可获得 **18 金币**；重甲兽人移动缓慢，但拥有较高护甲，击败可获得 **40 金币**。

**灾厄巫师**出现在翡翠回廊第五波，拥有 2400 点生命与独立 Boss 血条，能让整个战场的天气交替变化：

| 天气 | 持续时间 | 战场效果 |
| --- | --- | --- |
| 暴雪 | 12 秒 | 防御塔攻击速度降低 40% |
| 沙尘暴 | 12 秒 | 包括巫师在内的全部怪物移动速度提高 35% |

两种天气之间有 3 秒暂歇，随后循环。界面会显示天气效果与剩余时间，巫师死亡或抵达终点后恢复正常天气。冰霜塔的持续减速光环不受攻速变化影响，其减速可以与沙尘暴加速同时生效。

击败巫师可获得 **180 金币**；若让它抵达终点，将失去 **8 点基地生命**。

## 操作方式

| 操作 | 功能 |
| --- | --- |
| 拖动底部塔卡，在空石台松手 | 购买并建造防御塔 |
| 拖塔时点击鼠标右键 | 取消建造 |
| 鼠标滚轮 / 右下角 +、− | 缩放地图 |
| 按住鼠标左键拖动地图 | 平移视野 |
| WASD / 方向键 | 平移视野 |
| Home / 右下角“复位” | 恢复初始视野 |
| Esc / 右上角“菜单 Esc” | 打开或关闭暂停菜单；打开时取消拖塔 |

暂停菜单提供**继续游戏、重新开始、返回地图选择**。暂停期间战斗、出怪和天气倒计时停止，地图与建造操作也会暂停。

## 运行游戏

仓库包含 Unity 工程源码，可在编辑器中体验游戏。

1. 下载或克隆本仓库，在 Unity Hub 中添加仓库根目录，即包含 `Assets`、`Packages`、`ProjectSettings` 的文件夹。
2. 使用 **Unity 6000.3.27f1** 打开，等待依赖安装与资源导入完成。项目使用 URP 2D。
3. 打开 `Assets/Scenes/MainMenu.unity`，点击编辑器的 **Play**。
4. 点击“开始游戏”，选择地图，进入战场后拖卡建塔并开启第一波。

首次导入需要一些时间。完整操作说明见 [快速开始](Docs/GettingStarted.md)。
