# 图三轻暮色：局部照明试样

## 打开与比较

场景：`Assets/Scenes/GateOfTheDeadLightingPilot.unity`。

点击 Play 后，左上角提供三个对照按钮：

- **原亮度**：白色环境光，关闭试验局部光和后处理。
- **暮色试样**：冷色环境光、局部地面照明、柔光和轻量 Bloom。
- **仅环境光**：保留暮色环境，关闭局部光、光晕和 Bloom，便于看清光源对环境的贡献。

滑杆可调整环境亮度、局部照明和柔光扩散。Play 模式内的滑杆供观察效果；需要保留数值时，退出 Play 后选中 `Lighting Pilot - Local Study`，在 Inspector 修改对应字段并保存。

## 当前制作范围

只加强了**祭坛左侧橙火、左下紫火、双方对波及碰撞点**。其他火炬、传送门与符文仍保留原有特效，因此这是小范围照明试验，不代表全图照明定稿。

试样采用：

1. **受光实体**：底图、勇者、Boss 和悬石使用专用 `Sprite-Lit-Default` 材质。
2. **局部照明**：两盏火炬各用 Point Light 2D；两段光束使用随位置和长度变化的 Freeform Light 2D；碰撞点用独立点光。
3. **光晕与亮芯**：程序生成的柔光贴图位于亮芯下方；选中的发光精灵使用专用 HDR 材质，配合轻量 Bloom。原动画 PNG 保持不变。
4. **同步变化**：火炬照明轻微明暗变化，光束照明跟随推进点，封印完成后关闭对波的局部光。

默认环境强度 0.62，冷色为 RGB=(0.72,0.80,1.00)。局部强度倍率为 1，Bloom 强度为 0.16。这些是首版观察参数，仍待用户判断色彩和亮度。

## 场景与资源

试样从当前图三战斗场景复制，先保存了用户的当前修改，再制作独立场景。战斗场景的复制前后散列已核对一致。试样内关闭了 Gameplay 根对象，以便集中检查照明。
